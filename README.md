## 🛠️ Teknolojik Altyapı (Tech Stack)
### Front-End & UI
- **Framework & Runtime:** React 19, TypeScript, Vite
- **Styling:** Tailwind CSS v4, Custom Dark Glassmorphism Design
- **Icons & Components:** Lucide React, Custom SVG Icons, Responsive Navbar & Modal Engine
### Deploys & CI/CD
- **Hosting:** GitHub Pages
- **Automation:** GitHub Actions (`.github/workflows/deploy.yml`)

## 💻 Yerel Geliştirme (Local Setup)
Projeyi kendi bilgisayarınızda çalıştırmak için aşağıdaki adımları izleyebilirsiniz:
```bash
# 1. Repoyu klonlayın
git clone https://github.com/MrtBngl/MrtBngl.github.io.git
# 2. Proje dizinine gidin
cd MrtBngl.github.io
# 3. Bağımlılıkları yükleyin
npm install
# 4. Geliştirici sunucusunu başlatın
npm run dev
